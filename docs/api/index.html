Realm of AdAstra API

Sürüm 2.0.0-alpha.1 · OpenAPI 3.1 dosyası: docs/openapi.yaml · Bu sayfa koddan üretilir (node scripts/openapi-uret.mjs).

Oyun sunucusunun HTTP arayüzü. Hepsi JSON; hata gövdesi { error }. Oturum anahtarı giriş yanıtındaki token'dır (Authorization: Bearer …). Yönetici uçları ADMIN_TOKEN ister. Her yanıtta X-Request-Id başlığı vardır; 500 yanıtında aynı kimlik gövdede de döner (günlükte aranır). Bu dosya koddan üretilir: node scripts/openapi-uret.mjs

Açık giriş gerekmez · Oyuncu oturumu Authorization: Bearer <token> · Yönetici şifresi ADMIN_TOKEN
